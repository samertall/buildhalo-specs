## Functional Lens
- [ ] Install/connect Lens Studio, Lens Studio MCP, and Snap CLAD.
- [ ] Build in Lens Studio through CLAD from the approved brief.
- [ ] Include genuine `.esproj` project, assets and code under source control.
- [ ] SPECS Interactive Preview runs correctly, including Place guide, Done, Show motion, Back, Try again.
- [ ] Execute LEAF tests against the actual Lens, save observed results, and fix runtime issues.
- [ ] Manually check world placement, readability, and mouse-driven pinch interactions.

- [ ] Record the actual running **Lens Studio SPECS Interactive Preview**.

- [ ] Update Devpost story to reflect only verified work.
- [ ] Enter https://github.com/samertall/buildhalo-specs as the code repository.
- [ ] Enter public YouTube URL of **actual Lens Studio preview** (not existing browser concept video).
- [ ] Confirm all required fields and eligibility, then submit the existing Devpost project.

The GitHub repository URL is valid, but the hackathon requires the **actual Lens Studio project and skill-generated devpost/ folder**. Uploading planning files and an HTML storyboard does not by itself satisfy the code repository requirement.
